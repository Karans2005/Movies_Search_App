# 🎬 Movies Search App

A simple **Movie Search Application** built with **React.js + Vite**.

Search for your favourite movies, explore different categories, and browse **Hindi, Hollywood, and All Movies** in one place.

---

## ✨ Features

- 🔍 Search movies by name
- 🎬 Browse all movies
- 🇮🇳 Hindi movies
- 🇺🇸 Hollywood movies
- 📂 Movie categories
- ⭐ Movie information
- 🖼️ Movie posters
- 📱 Responsive design

---

## 🎞️ Categories

The app provides different categories to make browsing easier.

| Category | Description |
|---|---|
| 🎬 **All** | View all available movies |
| 🇮🇳 **Hindi** | Browse Hindi movies |
| 🇺🇸 **Hollywood** | Browse Hollywood movies |
| 📂 **Categories** | Explore movies by category |

---

## 🔎 Search

Search for a movie using the search bar.

For example:

```text
Avengers
Dangal
3 Idiots
KGF
Interstellar
```

The application filters the available movies according to the search.

---

## 📁 Movie Data

Movie information is stored locally in:

```text
detailed_movies_list_100.json
```

The JSON file contains the movie data used by the application.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Karans2005/Movies_Search_App.git
```

### Install Dependencies

```bash
npm install
```

### Run the Project

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.
